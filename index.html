Gmail Butler

Gmail Butler helps its owner organize a personal Gmail mailbox using configured routing rules and controlled label operations. This website explains the personal Stable Routing configuration. It is not a hosted mailbox service and does not connect visitors to Gmail.

What it does

The Stable Routing workflow uses permitted message metadata, such as sender and subject headers, and label state to match configured rules and apply approved labels. This workflow does not read message bodies, snippets or attachments. Other experimental or separately enabled workflows are outside this site's described configuration.

Google access

The desktop application uses Google OAuth and the Gmail API. Its Personal Direct configuration requests the gmail.modify scope. Google's permission is broader than each individual operation; local application controls limit the actions that run. The configured account is checked before a new credential is saved.

This application is intended for its owner, not public enrollment. Changing Google's OAuth publishing status does not launch the application, activate scheduled processing or grant other people access to the owner's mailbox.
