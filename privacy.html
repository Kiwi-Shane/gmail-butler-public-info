Privacy Policy

Effective October 2, 2026. This policy covers the owner-operated Personal Stable Routing configuration of Gmail Butler and this information website. It does not describe separate experimental integrations or other account configurations.

Information accessed and its purpose

Google account information is used to check that the connected account matches the configured owner. Message identifiers, sender and subject headers, label identifiers and label state are used to evaluate configured routing rules, execute authorized label operations, and record or reconcile their results. Gmail History information may be used to track changes within an authorized workflow. The Stable Routing workflow does not read message bodies, snippets or attachments.

Authorization and processing

The Personal Direct connection requests gmail.modify. This is a Gmail permission that can support more actions than this configured workflow uses. Application controls govern the particular operations. Google processes OAuth and Gmail API requests. Stable Routing's deterministic matching runs locally; this workflow does not send mailbox data to a hosted AI service.

This personal workflow is not designed to sell Google user data, serve advertising or train general-purpose AI models. Its use of information received from Google APIs is limited to the described mailbox-management purpose and is subject to the Google API Services User Data Policy, including the Limited Use requirements. This statement is a description and commitment, not a Google verification claim.

Local storage and protection

OAuth credentials are kept outside the source repository and protected through Windows DPAPI. The application can retain local configuration, operation journals, result references and protected metadata caches. Some records contain references or counters rather than raw mail fields. These protections do not replace operating-system account security or backup controls.

Retention and deletion

Local credentials and operation records can remain until the owner deliberately removes them. There is no universal automatic deletion deadline for all files or backups. The protected population cache enforces a seven-day validity period; expiry must not be interpreted as deletion of every related journal or backup.

To stop future access, revoke the application's authorization in Google Account connections and stop any local processing. Revocation does not erase local records or backups. To remove retained information, the owner must identify and remove the relevant credential, cache, journal and backup files, accounting for any records needed to restore previous label operations. Contact the owner through the support address on the OAuth consent screen for assistance.

This website

This static site contains no login, forms, analytics scripts, advertising or mailbox connection. GitHub Pages hosts it and logs visitor IP addresses for security, as described in GitHub's Privacy Statement. Visiting external links subjects the visitor to those services' policies. No mailbox data or OAuth credentials are published on this website.

Changes and contact

Review this policy before enabling a different workflow or external integration. Materially different data processing requires corresponding disclosure and authorization. Contact the application owner through the support address shown on the Google OAuth consent screen.
